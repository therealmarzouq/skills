# Skills

A collection of skills for writing clearer technical documentation.

Knowing whether your docs actually read well is hard. Agents tend to hedge, pad, and
repeat themselves. These skills encode a specific writing discipline so the output says
one true thing per sentence, plainly.

## Installation

```
npx skills@latest add therealmarzouq/skills
```

## Skills

1. **simplified-technical-english** — Write and rewrite docs, plans, READMEs, and specs
   using ASD-STE100 Simplified Technical English principles: short sentences, one
   approved meaning per word, active voice, no filler.
